## 🌐 关于这个网站

这个网站是我的个人知识库，用来整理和分享我在学习过程中的笔记与思考。目前主要涵盖三个板块：

- **Python**：从环境搭建到标准库，再到数据分析三剑客（NumPy、Pandas、Matplotlib），记录我的 Python 学习之路。
- **LaTeX**：一份从零开始的 LaTeX 基础指南，帮助需要排版数学公式和学术论文的朋友快速上手。
- **经济学**：以宏观经济学为主的学习笔记，涵盖核心概念、经济学派、政策分析和经典模型。

网站本身也是一个学习项目——通过 Markdown 编写内容，再转换为 HTML 页面，部署在 GitHub Pages 上。整个过程让我对前端开发和静态网站生成有了初步的了解。

> ⚠️ 本站仍在持续建设中，内容会不断更新和完善。

## 💡 我的理念

这句话是我一直以来的座右铭。无论是经济学模型、编程范式，还是我们对世界的认知，都不可能做到完美。但重要的是，我们可以通过不断学习和迭代，让自己的"模型"变得越来越有用。
